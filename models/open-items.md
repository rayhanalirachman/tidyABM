# Open items

What the grammar still cannot say. Entries leave this page when they are closed
rather than staying on it struck through: the history of what closed, and of
what closing it showed, is in
[what each stress test changed](what-changed.md).

Two entries, and neither is a request for expressiveness.

- **No spatial primitive.** Every model here is aspatial or network-based by
  design. A lattice or continuous space would be a different project, not an
  extension of this one. `pair = "nearest"` covers similarity-space models, and
  now that it takes a cost expression, and `abm_neighbours()` takes a `within`
  condition, it covers rather more of them than it did. That is as close as this
  grammar gets, and going further would mean deciding what a neighbourhood, a
  boundary and a move are, which is a design project of its own.
- **Two models are still written around a limitation that was not there.** PD
  N-Person (26) holds per-opponent memory as N² scalar columns and the genetic
  algorithm (35) holds a genome as L of them, both written in the rounds when
  "no set-valued agent state" was believed. A list column holds either one, as
  the naming game (40), the minority game (41) and now El Farol (14) do. The
  pages say so. The rewrites are work nobody has done, not something the grammar
  is missing.
